## 1. 主機發送詢問格式 (Master Request)

| **欄位名稱** | **長度 (Byte)** | **說明**                         | **範例 (Hex)** |
| -------- | ------------- | ------------------------------ | ------------ |
| 起始碼      | 1             | 固定為 0xB0 有無需要待討論               | B0           |
| 功能碼      | 1             | 根據功能該發定義 03 讀取                 | 03           |
| 開始暫存器位址  | 2             | 包含櫃號的高低位元位址                    | 00 00        |
| 暫存器數量    | 2             | 欲讀取的暫存器個數 (Quantity)           | 1B           |
| 校驗碼      | 2             | 標準 Modbus CRC-16 (Low Byte 在前) | XX XX        |
- **命令範例**：`B0 03 10 00 00 1B CRC_L CRC_H`

## 2. 設備回應格式 (MCU Response / Notify)

| **欄位名稱** | **長度 (Byte)** | **說明**                             | **範例 (Hex)**    |
| -------- | ------------- | ---------------------------------- | --------------- |
| 起始碼      | 1             | 固定為 0xB0 有無需要待討論                   | B0              |
| 功能碼      | 1             | 根據功能該發定義 03 讀取                     | 03              |
| 狀態碼      | 1             |                                    |                 |
| 開始暫存器位址  | 2             | 回報資料的起始暫存器位址 (高位在前)                | 00 00           |
| 暫存器數量    | 2             | 這包資料包含的暫存器個數 (高位在前)                | 1B              |
| 資料內容     | 變動            | 連續的二進位資料（長度固定為 數量 $\times$ 2 Byte） | 13 EF 00 00 ... |
| 校驗碼      | 2             | 整個封包的 CRC-16 檢查碼                   | XX XX           |

| **欄位名稱** | **長度 (Byte)** | **說明**                             | **範例 (Hex)**    |
| -------- | ------------- | ---------------------------------- | --------------- |
| 起始碼      | 1             | 固定為 0xB0 有無需要待討論                   | B0              |
| 功能碼      | 1             | 根據功能該發定義 03 讀取                     | 03              |
| 開始暫存器位址  | 2             | 回報資料的起始暫存器位址 (高位在前)                | 00 00           |
| 暫存器數量    | 2             | 這包資料包含的暫存器個數 (高位在前)                | 1B              |

| 校驗碼      | 2             | 整個封包的 CRC-16 檢查碼                   | XX XX           |
- **回應範例**：`B0 03 10 00 00 1B 13 EF 00 00 ... CRC_L CRC_H`
