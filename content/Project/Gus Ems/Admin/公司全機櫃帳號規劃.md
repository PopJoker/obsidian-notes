# 解耦新架構，建置新 Web 運維端並擴充身分識別 API

- **優點：**
    - **特化 UI 設計：** 前端版面全新重構，能針對「全機櫃狀態（BMS/EMS）」進行客製化的大螢幕或高密度看板規劃。
    - **零侵入性：** 完全不需要改動現行的客戶端 Web APP，將營運風險降至最低。
    - **核心業務隔離：** 兩端（客戶端與運維端）功能徹底解耦，互不干擾，資安邊界清晰。
    - **跨平台體驗：** 同樣支援 PWA 技術，可快速打包成桌面/行動端快顯軟體，無需負擔 App 開發成本。
    - **利於未來維護：** 新建獨立專案，程式碼乾淨，方便未來功能迭代與模組化管理。
- **缺點：**
    - **初期投入高：** 涉及全新前端建置與後端 API 擴充，開發與整體整合測試的時程較長。
    - **鑑權機制成本：** 如需要對外，後端需額外設計、修改 API，建立額外認證機制。
