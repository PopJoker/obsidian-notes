#### `users` (PM 帳號表)
- `user_id`: UUID (PK)
- `name`: VARCHAR
- `email`: VARCHAR (Unique)
- `role`: VARCHAR (e.g., 'PM', 'Admin')
#### `customers` (客戶公司表)
- `pm_id`: FK -> `users.user_id` (主要負責 PM)
- `customer_id`: UUID (PK)
- `company_name`: VARCHAR (公司名稱，關聯 Key)
-  `customer_name`: VARCHAR (聯絡人姓名，關聯 Key)
-  `customer_mail`: VARCHAR (聯絡人mail，關聯 Key)
- `customer_phone`: VARCHAR (聯絡人phone，關聯 Key)
- `created_at`: TIMESTAMP
#### `reports` (報表主表)
- `report_id`: UUID (PK)
- `report_code`: VARCHAR (報表編號)
- `pm_id`: FK -> `users.user_id`
- `contact_id`: FK -> `contacts.contact_id` (必要關聯)
- `status`: VARCHAR (e.g., 'DRAFT', 'GENERATED', 'ARCHIVED')
- `spec_series`: INT (串聯數，預設 6)
- `spec_parallel`: INT (並聯數)
- `cell_num`: VARCHAR (電芯型號/料號)
- `cell_type`: VARCHAR (電芯種類，如 18650, 21700, 磷酸鐵鋰等)
- `connection_method`: VARCHAR (串併方式)
- `processing_method`: VARCHAR (加工方式)
- `connector_type`: VARCHAR (連接器類型)
- `wire_length`: DECIMAL (線長，mm/cm)
- `outer_casing`: VARCHAR (外包覆材質)
- `array_arrangement`: ENUM ('I', 'U', 'II') (排列方式)
- `has_bms`: BOOLEAN (預設 true)
- `bms_spec_limit`: VARCHAR (限制 6S?P)
- `weight_g`: DECIMAL (估計重量)
- `dimensions_mm`: VARCHAR (尺寸 L_W_H)
- `delivery_days`: INT (交期天數)
- `tiered_pricing`: INT (報表價格)
- `created_at`: TIMESTAMP
- `updated_at`: TIMESTAMP
#### `report_histories` (歷史紀錄與版本控制)
- `history_id`: UUID (PK)
- `report_id`: FK -> `reports.report_id`
- `version`: INT (版本號)
- `snapshot_data`: JSONB (當下整份報表與聯絡人的資料快照)
- `created_by`: FK -> `users.user_id`
- `created_at`: TIMESTAMP
