	  - [ ] 執行 Python 腳本，發送 `*CLS;*IDN?\n`[cite: 3]。
	  - [ ] 正確讀回包含 `ITECH,IT-M3912C-80-240...` 之設備識別字串。
	- [ ] **1.3 遠端控制模式切換與鎖定**
	  - [ ] 發送 `SYSTem:REMote`，確認設備面板顯示 Remote 標示且面板按鍵被鎖定。
	  - [ ] 發送 `SYSTem:LOCal`，確認面板恢復手動操作。
	- [ ] **2.1 軟體保護極限設定 (Protection Limits)**
	  - [ ] 發送 `VOLT:PROT 60.0` 設定軟體 OVP[cite: 3]。
	  - [ ] 發送 `CURR:PROT 20.0` 設定軟體 OCP[cite: 3]。
	  - [ ] 發送 `POW:PROT 100.0` 設定軟體 OPP[cite: 3]。
	- [ ] **2.2 電壓/電流/功率設定與讀回驗證**
	  - [ ] 設定 `VOLT 12.0` $\rightarrow$ 發送 `VOLT?` 讀回 `12.000`[cite: 3]。
	  - [ ] 設定 `CURR 5.0` $\rightarrow$ 發送 `CURR?` 讀回 `5.000`[cite: 3]。
	  - [ ] 設定 `POW 100.0` $\rightarrow$ 發送 `POW?` 讀回 `100.000`[cite: 3]。
	- [ ] **2.3 輸出開關控制 (Output Switch)**
	  - [ ] 發送 `OUTP ON` 啟動輸出，確認面板 Output 燈號亮起。
	  - [ ] 發送 `OUTP OFF` 關閉輸出，確認面板 Output 燈號熄滅。

	- [ ] **3.2 硬體降載邏輯觀察 ($I \times V > P$)**[cite: 3]
	  - [ ] 啟動 `OUTP ON`，調整負載端使端電壓拉低至 $10\text{V}$（理論全載電流為 $10\text{A}$，功率達 $100\text{W}$，超過限制的 $50\text{W}$）[cite: 3]。
	  - [ ] 連續發送 `MEAS:VOLT?;CURR?;POW?\n` 讀取實測值[cite: 2]。
	  - [ ] 發送 `STATus:OPERation:CONDition?` 讀取設備當前運作模式狀態。
	- [ ] **3.3 交調機制判定**
	  - [ ] **選項 A (硬體自動限制)**：實測電流自動被限制在 $5\text{A}$ ($50\text{W} / 10\text{V} = 5\text{A}$)，無跳跳保護。
	  - [ ] **選項 B (觸發保護關斷)**：設備跳發 OPP 告警並切斷輸出。
	  - [ ] **選項 C (需軟體補償)**：硬體無限制，確認需要由阿梅（Py Server）即時採集 $V$，動態計算並修正 $I = P_{limit} / V$ 再寫入 `CURR`[cite: 1, 3]。
	- [ ] **4.1 採集 Latency (Polling Speed) 測試**
	  - [ ] 以迴圈持續發送 `MEAS:VOLT?;CURR?;POW?\n` 100 次[cite: 2]。
	  - [ ] 計算單次「發送+讀回」的平均 Latency（目標：$\le 50\text{ms}$/次）[cite: 2]。
	- [ ] **4.2 突發拔線 / 斷線反應測試**
