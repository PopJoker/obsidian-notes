# 理想架構
1. 整體架構梳理
	1. 充放電行為
		- 以API命令為主，Web會串接Heartbeat Websocket 來確認與阿梅的連接狀況，如斷線立即通知。
	2. 設備心跳顧慮
		- [Heartbeat Websocket 參考 ](https://django-websocket-redis.readthedocs.io/en/latest/heartbeats.html) 以固定頻率回復簡單Response的方式確認無斷線，相較API回復時間有更快的反應速度，可以快速反應兩種情況。
			- 伺服器斷線 按照排程與保護點進行
			- 與設備連接斷線 想辦法警告顯場與使用者[問題一]
	3. 伺服器架構與
	- 阿梅架設Py server 負責static web、API、機體通訊，網頁用Vue，存取數據目前說是VPS1但這樣要另外開Port或新增API[問題二]，支援本地存取資料表，資料夾位子與名稱存本地。
